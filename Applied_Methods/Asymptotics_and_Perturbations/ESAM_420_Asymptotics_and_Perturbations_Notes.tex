\section{Motivating Examples}
Suppose we want to launch a projectile vertically into the air and we want to create a model. We are launching it vertically so we do not have to worry about vectors. We start with Newton's Law of Gravity so we can say that 
\begin{equation*}
    \odt{r}{t} =-G\frac{M_e }{r^2}
\end{equation*}
where $r$ is the distance from the center of the Earth, $G$ is the gravitational constant, and $M_e$ is the mass of the Earth. However, we want to know how far from the surface of the Earth our projectile goes so we define $r=h+R$ where $R$ is the radius of the Earth and $h$ is the height of the projectile relative to the ground. Since $dr=dh$, we have that 
\begin{equation*}
    \odt{h}{t} = - G\frac{M_e}{(h+R)^2} 
\end{equation*}
Recalling that $g=\frac{GM_e}{R^2}$, we rewrite the equation as 
\begin{equation*}
    \odt{h}{t} = -\frac{gR^2}{(h+R)^2}
\end{equation*}
This equation has no analytical solution. However, if make the approximation $h\ll R$, we can obtain an \emph{asymptotic solution}. 
\begin{equation*}
    \odt{h}{t} = -g 
\end{equation*}
which if we set the initial conditions to be $h(0) = 0, h'(0) = v_0$, we have that the solution is 
\begin{equation*}
    h(t) = v_0t-\frac{1}{2}gt^2
\end{equation*}
The problem with this is we have no semi-``precise" way to justify when we can make this assumption. We also cannot add any correcting factors. We usually start these by non-dimensionalizing. This allows us to zoom to the scale we want to work with and justify what is ``small." For the gravity problem, let us define the characteristic length and times to be 
\begin{equation*}
    L_c = \frac{v_0^2}{g} \twen T_c= \frac{v_0}{g}
\end{equation*}
We also define some new normalized variables relative to these characteristic norms (I don't want to use variables and they're mainly about magnitudes, hence norms)
\begin{equation*}
    x=\frac{h}{L_c} \twen \tau =\frac{t}{T_c}
\end{equation*}
We can transform $\odt{h}{t}\rightarrow \odt{x}{\tau}$ via the chain rule 
\begin{equation*}
\begin{split}
    \od{x}{\tau} &=\od{x}{h} \od{h}{t} \od{t}{\tau} = \frac{1}{L_c}\od{h}{t} \frac{T_c}{1} \\
    \od{h}{t}& = \frac{L_c}{T_c} \od{x}{\tau} \\
    \Rightarrow\odt{h}{t}&=\od{}{t}\left( \frac{L_c}{T_c} \od{x}{\tau}\right) =\od{}{t}\od{t}{\tau}\left( \frac{L_c}{T_c} \od{x}{\tau}\right) = \frac{L_c}{T_c^2}\odt{x}{\tau}
\end{split}
\end{equation*}
So our equation now becomes 
\begin{equation*}
    \begin{split}
        \frac{L_c}{T_c^2} \odt{x}{\tau} &= -\frac{gR^2}{(xL_c+R)^2} = -\frac{gR^2}{R^2(x\frac{L_c}{R}+1)^2} \\
        \odt{x}{\tau}&= -\frac{1}{(x\varepsilon+1)^2} \twen \varepsilon=\frac{L_c}{R} = \frac{v_0^2}{gR}
    \end{split}
\end{equation*}
We then guess our solution is some sort of expansion based off this small parameter of the form 
\begin{equation*}
    x(t) = x_0 + \varepsilon x_1+\varepsilon^2x_2 +\ldots
\end{equation*}
Our small parameter being the ratio of the characteristic length to the radius of the Earth shows us exactly when we can make certain assumptions.\\\\
Another application is the Navier-Stokes equations.
\begin{equation*}
    \begin{split}
        \nabla \cdot \vec{u} &= 0 \text{ (incompressibility equation)}\\
        \rho\left(\pd{\vec{u}}{t} + \left( \vec{u}\cdot \nabla \right) \vec{u} \right) &=-\nabla p+\mu \nabla^2 u \text{ (equation of motion)}
    \end{split}
\end{equation*}
If we non-sensationalize such that $(\tilde x, \tilde y, \tilde z) = \frac{1}{L}(x,y,z), \tilde{\vec{u}} = \frac{\vec{u}}{u_c}, \tilde p = \frac{p}{p_c}, \tilde t = \frac{t}{T_c}, T_c =\frac{L_c}{u_c}$. This transforms our equation into 
\begin{equation*}
    \frac{\rho u_c}{T_c} \pd{\tilde{ \vec{u}}}{\tilde t} + \frac{\rho u_c^2}{L_c} \left(\tilde{\vec{u}} \cdot \tilde{\nabla} \right)\tilde{\vec{u}} = -\frac{p_c}{L_c} \tilde{\nabla} \tilde p + \frac{\mu U_c}{L_c^2}\tilde{\nabla ^2}\tilde u
\end{equation*}
Notice that the first two coefficients of the left hand side are equal and so we can rewrite the left hand side as one differential operator $\frac{D\vec{u}}{D\tilde t}$. Doing some algebra we get that 
\begin{equation*}
    \operatorname{Re}\frac{D\vec{u}}{Dt} = -\frac{p_c L_c}{\mu u_c} \tilde{\nabla}p + \tilde{\nabla^2}\tilde u
\end{equation*}
where Re is the Reynold's number which is the ratio of inertial versus viscous forces in a flow. 
\begin{equation*}
    \operatorname{Re} = \frac{\rho u_c L_c}{\mu}
\end{equation*}
If we take the limit as the Reynold's number go to zero, we go into the length scale of bacteria typically. If we have $\frac{p_cL_c}{\mu u_c} = 1$, we then have that the characteristic pressure is $p_c =\frac{\mu u_c}{L_c}$. Rearranging the equation we get 
\begin{equation*}
    \nabla p= \mu \nabla^2 \vec{u}
\end{equation*}
which is known as the Stoke's limit. If instead we take the limit as the Reynold's number goes to infinity and if we set the characteristic pressure to be $p_c=\rho u_c^2$, we get 
\begin{equation*}
    \frac{D \vec{u}}{D\tilde{t}} = -\nabla p +\frac{1}{\operatorname{Re}}\tilde{\nabla^2}\tilde u
\end{equation*}
The Laplacian term goes to zero and we have the Euler Equation for invsicid flow 
\begin{equation*}
    \rho\left( \pd{u}{t}+(\vec{u} \cdot \nabla) \vec{u} \right) = -\nabla p
\end{equation*}
From this we can get d'Alembert's paradox which states that the force of drag is zero on a body moving at a constant velocity in an inviscid fluid contrary to observations. Due to asymptotics, we can add correction terms to resolve this paradox.
\section{Algebraic Equations}
Suppose we want to solve the algebraic equation 
\begin{equation*}
    x^2+2\varepsilon x-1=0 \twen \varepsilon\ll 1
\end{equation*}
Analytically we can solve this to get that $x_{1,2}=-\varepsilon\pm \sqrt{1+\varepsilon^2}$. If we can't analytically solve, we can use two methods to approximate: expansion or iteration. Let us start with the expansion method first.
\subsection{Expansion Method}
Let us start with the zeroth-order approximation and set $\varepsilon=0$. We get that our solutions are $x_{0_{1,2}} = \pm 1$. We then make the guess that our solution can be expressed as the power series 
\begin{equation*}
    x=x_0+\varepsilon x_1+\varepsilon^2x_2+\ldots
\end{equation*}
We then plug that back into our equation and match together powers of $\varepsilon$ up until the powers of epsilon that we desire. Doing so gets us 
\begin{equation*}
    \begin{split}
        (x_0+\varepsilon x_1+\varepsilon^2x_2+\ldots)^2+2\varepsilon(x_0+\varepsilon x_1+\varepsilon^2x_2+\ldots)-1=0 \\
        1+2\varepsilon x_1+2\varepsilon^2 x_2+\varepsilon^2x_1+\ldots+2\varepsilon+2\varepsilon^2x_1+\ldots-1=0
    \end{split}
\end{equation*}
Grouping them together by powers of epsilon gives 
\begin{equation*}
    \varepsilon(2x_1+2) +\varepsilon^2(2x_2+x_1^2+2x_1)=0 \,\,\, \forall \varepsilon
\end{equation*}
Since this equation must be true for all $\varepsilon$, we have that the parenthesis terms must be 0 and so we solve for $x_1$ and then plug that into the $\varepsilon^2$ expression to solve for $x_2$.
\begin{equation*}
    \begin{split}
        \varepsilon:&\,\,\,  2x_1+2=0 \rightarrow x_1=-1 \\
        \varepsilon^2:& \,\,\, 2x_2+1-2=0 \rightarrow x_2 = \frac{1}{2}
    \end{split}
\end{equation*}
Our three-term expansion is therefore 
\begin{equation*}
    x=1-\varepsilon+\frac{1}{2}\varepsilon^2
\end{equation*}
If we take the binomial expansion of our analytical solution, we find the same thing. 
\subsection{Iteration Method}
We generally solve for the highest order of $x$ 
\begin{equation*}
    x^2=1-2\varepsilon x \rightarrow x=\pm \sqrt{1-2\varepsilon x}
\end{equation*}
The iteration method says that 
\begin{equation*}
    x_{n+1}=\pm \sqrt{1-2\varepsilon x_n}
\end{equation*}
We start with the zeroth-order approximation 
\begin{equation*}
    \begin{split}
        \varepsilon=0 \rightarrow x_0=\pm 1\\
        \varepsilon^1 \,\,\,x_1=\sqrt{1-2\varepsilon} = 1-\varepsilon \\
        \varepsilon^2\,\,\, x_2 = \sqrt{1-2(1-\varepsilon)\varepsilon} = 1-\varepsilon(1-\varepsilon)-\frac{1}{8}(2\varepsilon(1-\varepsilon))^2
    \end{split}
\end{equation*}
Cleaning all of this up we get the same thing as the previous methods 
\begin{equation*}
    x_3=1-\varepsilon+\frac{1}{2}\varepsilon^2
\end{equation*}
The iteration method effectively is a spiral from an initial approximation leading to a value of $x_n$ which we then iterate on more to hopefully get to the desired root. However, if the function changes too much too quickly, this can lead to spiraling away. \\\\
The expansion and iteration methods are good when the zeroth-order approximation doesn't change the nature of the equation (e.g., if we have $\varepsilon x^2+x+1=0$, the zeroth-order approximation would change the equation from a quadratic to a linear equation).
\\\\
Let us now consider a case when we can't use the highest order term to begin our iteration.
\begin{equation*}
    x^2+x-\varepsilon=0
\end{equation*}
The key thing here is to setup and iteration such that it converges to the desired value. In order for that to happen, we need on an interval $I$ around the root to have the following condition: $|f'(x)|<1\,\,\,\forall x\in I$. It is also worth noting that knowing what the unperturbed function looks like by moving all of the $\varepsilon$ terms to one side and ignoring it (in this case, it would be $x^2+x=0$). Here we can see the unperturbed roots are $x=-1$ and $x=0$. Let us try to find the root around $x=-1$. We can do this with the setup 
\begin{equation*}
    x^2=\varepsilon-x
\end{equation*}
By dividing by $x$, we can find the relation 
\begin{equation*}
    x=\frac{\varepsilon}{x_n}-1
\end{equation*}
If we let the right hand side equal $f(x)$, we find that the derivative is $|f'(x)|=\frac{\varepsilon}{x_n^2}$. Since $\varepsilon$ is assumed small, our convergence condition is satisfied.

\subsection{Method of Dominant Balance}
Let us take a look at the algebraic equation 
\begin{equation*}
    \varepsilon x^2+x-1=0
\end{equation*}
If we do either the expansion or iteration method, we change the number of roots we get. Let us go try out this method to see what happens. We once again start with the $\varepsilon=0$ term to get that $a_0=1$. We shall use expansion here and guess $x=1+\varepsilon a_1+\varepsilon^2 a_2+\ldots$. Plugging this in we get 
\begin{equation*}
    \begin{split}
        \varepsilon(1+\varepsilon a_1+\ldots)^2+(1+\varepsilon a_1+\ldots)-1=0 \\
        \varepsilon(1+2\varepsilon a_1+\ldots)+(1+\varepsilon a_1+\ldots)-1=0 \\
        \varepsilon(1+a_1)+\mathcal{O}(\varepsilon^2)=0 \rightarrow a_1=-1
    \end{split}
\end{equation*}
Therefore our two term expansion is $x=1-\varepsilon +\mathcal{O}(\varepsilon^2)$. If we look at the actual roots using the quadratic formula and binomial expand the square root, we get the same thing for the positive root.
\begin{equation*}
    \begin{split}
        x=\frac{-1\pm \sqrt{1+4\varepsilon}}{2\varepsilon} = \frac{1}{2\varepsilon}\left(-1 \pm (1+\frac{1}{2}4\varepsilon - \frac{1}{8}(4\varepsilon)^2 +\ldots \right) \\
        x_{+} =\frac{1}{2\varepsilon}(2\varepsilon-2\varepsilon^2) = 1-\varepsilon+\ldots
    \end{split}
\end{equation*}
If we look at the negative root, we find that there is a $\frac{1}{\varepsilon}$ term which explains the behavior at $\varepsilon=0$ and why it doesn't show up.
\begin{equation*}
    x_{-} =\frac{1}{2\varepsilon}(-2-2\varepsilon+2\varepsilon^2) = -\frac{1}{\varepsilon}-1+\varepsilon+\ldots
\end{equation*}
equipped with this knowledge, let us introduce the Method of Dominant Balance. This method allows us to rigorously find the other root by introducing a rescaled variable $y=\frac{x}{\delta}$ where $\delta$ is some unknown which may be a function. This relation implies that $x=\delta y$. The reason we are doing this is because in the original equation we are strictly assuming $x=\operatorname{ord} (1)$ with respect to $\varepsilon$ and so as such, the linear and constant terms are both order 1 whereas the quadratic term is very small. As such, the dominant balance was between $x$ and $-1$ and that's why we only recovered one of the roots. This rescaling shifts the dominant balance. Since we know before hand that the irregular root $x\sim \frac{1}{\varepsilon}$, let us plug into the original equation and see what happens.
\begin{equation*}
    \begin{split}
        \varepsilon\left(\frac{1}{\varepsilon}\right)^2 + \left(\frac{1}{\varepsilon}\right) -1=0 \\
        \frac{1}{\varepsilon}+\frac{1}{\varepsilon}-1=0
    \end{split}
\end{equation*}
We can now see that as $\varepsilon \rightarrow 0$, the quadratic and linear terms are now big compared to the constant. That is effectively what the Method of Dominant Balance is doing except we do not have prior knowledge of what this relation is. As such, we substitute our relation for $x$ to arrive at 
\begin{equation*}
    \varepsilon \delta^2 y^2+\delta y-1=0
\end{equation*}
and now we balance the two other terms (with the assumption that $y$ is strictly order 1). For this to happen, we must have the relation 
\begin{equation*}
    \varepsilon \delta^2\sim\delta
\end{equation*}
which we can then extract the relation $\delta \sim \frac{1}{\varepsilon}$. This is exactly the term that caused the negative root to vanish when we used the quadratic formula to solve for it. We now have the relation $x=\frac{1}{\varepsilon}y$. We are now able to substitute this back in for every $x$ in the original algebraic equation and derive a new one that we can apply our previous methods on.
\begin{equation*}
    \begin{split}
        \frac{1}{\varepsilon}y^2+\frac{1}{\varepsilon}y-1&=0\\
        \Rightarrow y^2+y-\varepsilon&=0
    \end{split}
\end{equation*}
We cannot find the solutions to this using iteration because we would have the relation $y=\pm \sqrt{\varepsilon-y}$ which if we tried to find the leading term expression, we would result in complex values. That is why we shall use expansion 
\begin{equation*}
    \begin{split}
        y=a_0+\varepsilon a_1+\varepsilon^2 a_2+\ldots \\
        (a_0+\varepsilon a_1+\ldots)^2+(a_0+\varepsilon a_1+\ldots)-\varepsilon=0 \\
        a_0^2+2\varepsilon a_0a_1+a_0+\varepsilon a_1-\varepsilon=0 \\
        a_0(a_0+1)+\varepsilon(2a_0a_1+a_1-1)=0
    \end{split}
\end{equation*}
Solving for $a_1$ in the $\varepsilon$ term we see that 
\begin{equation*}
    a_1 =\frac{1}{2a_0+1}
\end{equation*}
We see that $a_0=0$ or $a_0=-1$. In the first case, we have that $a_1=1$ and so the expansion for that is $y=\varepsilon+\ldots$ and for the second, we have $-1-\varepsilon+\ldots$. Subbing this back into the relation for $x=\frac{1}{\varepsilon}y$, we get the approximations 
\begin{equation*}
    \begin{split}
        x_1 &=1+\ldots \\
        x_2&=-\frac{1}{\varepsilon}-1+\ldots
    \end{split}
\end{equation*}

Let us look at another example 
\begin{equation*}
    \varepsilon x^3-x+1=0
\end{equation*}
Finding the regular root is pretty trivial so we shall ignore it. We start with the ansatz that $x=\delta y$.
Subbing this in we get 
\begin{equation*}
    \varepsilon\delta^3y^3-\delta y+1=0
\end{equation*}
We can choose to either balance the first and second term or the first and third term. If we choose to balance the first and last term, we get that $\delta \sim \varepsilon^{-1/3}$. Plugging this in we would get 
\begin{equation*}
    y^3-\varepsilon^{-1/3}y+1=0
\end{equation*}
The first and third terms are now both order 1 but the middle term is huge as $\varepsilon\rightarrow0$ which is impossible since you now have an unbalanced term. Therefore the correct terms to balance were the first and second. We then get $\delta \sim \frac{1}{\sqrt \varepsilon}$ and so 
\begin{equation*}
    \frac{1}{\sqrt \varepsilon}y^3-\frac{1}{\sqrt \varepsilon}y+1=0 \rightarrow y^3-y+\sqrt \varepsilon =0.
\end{equation*}
We can now iterate/expand to find the roots we couldn't find earlier. Additionally, it is worth noting since the non-homogeneity is $\sqrt{\varepsilon}$, we should have our expansion be 
\begin{equation*}
    y=y+0+\sqrt \varepsilon y_1+(\sqrt \varepsilon)^2y_2+\ldots
\end{equation*}

\section{Transcendental Equations}
\subsection{Expansion}
Let us take the equation 
\begin{equation*}
    xe^{-x}=\varepsilon
\end{equation*}
as an example. By simply plotting it, we see that there exists a root close to $x=0$ and a large root as $x\rightarrow \infty$. One way to do it is to take the two term expansion for $e^{-x}$ and then iterate on that. Doing so we get 
\begin{equation*}
    \begin{split}
        x_{n+1}&=\varepsilon+x_n^2\\
        x_1&=\varepsilon\\
        x_2&=\varepsilon+\varepsilon^2
    \end{split}
\end{equation*}
To find the other root, we take the natural log of both sides and we get 
\begin{equation*}
    \ln x-x=\ln \varepsilon
\end{equation*}
we then make the guess 
\begin{equation*}
    x=\delta_0(\varepsilon)+\delta_1(\varepsilon)+\ldots
\end{equation*}
where each of the basis functions are to be solved for on their own. We therefore arrive at 
\begin{equation*}
    \ln(\delta_0)-\delta _0=\ln \varepsilon
\end{equation*}
We want to balance the second and third terms because if we did the first and third, we would get that $\delta_0=\varepsilon$ and we are trying to find the larger root. We then find that $\delta_0=-\ln \varepsilon = \ln \frac{1}{\varepsilon}$. We now plug this $\delta_0$ back into our ansatz and solve for $\delta_1$ 
\begin{equation*}
    \ln \left( \delta_0\left(1+\frac{\delta_1}{\delta_0} \right) \right) - \delta_0 -\delta_1=\ln \varepsilon \\
    \ln \delta_0+\ln\left(1+\frac{\delta_0}{\delta_1}\right)-\delta_0-\delta_1=\ln \varepsilon \\
    \ln \delta_0+\ln\left(1+\frac{\delta_0}{\delta_1} \right) -\delta_1=0
\end{equation*}
We now want to balance the first and third term since first, it contains $\delta_1$ which we are solving for, and secondly, $\delta_0$ dominates over $\delta_1$ the second term is close to zero. We then find that 
\begin{equation*}
    \delta_1=\ln\left(\ln\frac{1}{\varepsilon}\right)
\end{equation*}
It is also worth noting that previously we didn't care about signs or constants. That's because we were simply content with finding the same order of magnitude approximations. However, we are now looking for the \emph{functions} for our expansion and so now we do care about these things.
\subsection{Implicit Equations}
Let us look at the equation 
\begin{equation*}
    x^2+xy-y^3=0
\end{equation*}
Say we want to know the asymptotic behavior of $y(x)$ as $x\rightarrow \infty$. We have three total ways to balance the terms in this equation:
\begin{enumerate}
    \item $x^2\leftrightarrow xy \Leftrightarrow x^2+xy=0 \rightarrow y=-x$
    \item $xy \leftrightarrow y^3 \Leftrightarrow xy-y^3=0 \rightarrow y=\sqrt{x} $ 
    \item $x^2\leftrightarrow y^3 \Leftrightarrow x^2-y^3=0 \rightarrow y=x^{2/3}$
\end{enumerate}
If we substitute the each of the results we can check the balances to see which one is correct. 
\begin{enumerate}
    \item $x^2 \,\,\,xy\sim-x^2 \,\,\, y^3\sim-x^3$ We see that as $x\rightarrow \infty$, the last term isn't balanced.
    \item $x^2 \,\,\, xy \sim x^{3/2} \,\,\, y^3\sim x^{3/2}$ This is the wrong choice as well since the $x^2$ term dominates even though we wanted the other two terms to dominate
    \item $x^2\,\,\, xy\sim x^{5/3} \,\,\, y^3\sim x^2$ We see this is the correct balance because the balanced terms are the dominant terms in the equation. 
\end{enumerate}
We now guess that 
    \begin{equation*}
        y(x)=x^{2/3} + g(x)
    \end{equation*}
    where $g(x)$ is some correction term we seek to find. We want $g(x)$ to be less than the dominant term. Or in other words, 
    \begin{equation*}
        \lim_{x\rightarrow \infty}\frac{g}{x^{2/3}}\rightarrow 0
    \end{equation*}
    We now plug this into our equation and we get 
    \begin{equation*}
        x^2+x^{5/3}+xg=x^2+3x^{2/3}g+3x^{4/3}g+g^3
    \end{equation*}
    When we balance $x^{5/3}=3x^{4/3}g$ we get that $g=\frac{1}{3}x^{1/3}$ which is the only correct balance (one can see for others by plugging in their relation and seeing if it matches what we desire). We now have that 
    \begin{equation*}
        x^{5/3}+x^{4/3}=3x^{4/3}+3x^{5/3}+x
    \end{equation*}
    and we see that our highest order terms are balanced which shows that are balance was correct. As such,  
    \begin{equation*}
        y(x)= x^{2/3}+\frac{1}{3}x^{1/3}+\ldots
    \end{equation*}

\subsection{Approximating Integrals}
Say we have some function $f(x,\varepsilon)$ which can be represented 
\begin{equation*}
    f(x,\varepsilon)=\sum_n a_n(x)\varphi_n(\varepsilon)
\end{equation*}
We can integrate this function (however we can't differentiate because differentiation often causes the magnitude to increase with every derivative) and approximate the value of integrals. Let us take a look at the Stieltjes function (? can't find the name online but this is what Gemini gave) 
\begin{equation*}
    I(\varepsilon)=\int^\infty_0\frac{e^{-t}}{1+\varepsilon t} dt
\end{equation*}
We can define 
\begin{equation*}
    I_n=\int^\infty_0\frac{e^{-t}}{(1+\varepsilon t)^n}dt
\end{equation*}
If we differentiate by parts, we can derive the recurrence relation as follows 
\begin{equation*}
    I_n = -\frac{e^{-t}}{(1+\varepsilon t)^n}\Bigg|^\infty_0 -n\varepsilon\int^\infty_0\frac{e^{-t}}{(1+\varepsilon t)^{n+1}}dt = 1-n\varepsilon I_{n+1}
\end{equation*}
We find that $I_1=1-\varepsilon I_2$. We also see that $I_2=1-2\varepsilon I_3$ and we can sub this back in to get that $I_1=1-\varepsilon+2\varepsilon^2 I_3$. We prefer this method to generate the integral approximation since we are adding smaller and smaller corrections with every approximation. We can ultimately arrive at 
\begin{equation*}
    I(\varepsilon)=\sum^N_{n=0}(-1)\varepsilon^n n! +\operatorname{error}(N)
\end{equation*}

\subsection{Asymptotic Expansion}
Let us say there exists a function such that 
\begin{equation*}
    f(\varepsilon)=\sum^N_{n=1} a_n\varphi_n(\varepsilon) + \operatorname{error}
\end{equation*}
where the error is $o(\varphi_{N})$ for some basis of function space $\varphi_1,\varphi_2,\ldots,\varphi_N,\varphi_{N+1},\ldots$. The interesting thing is that the series need not be convergent. Let us take a look at the error function 
\begin{equation*}
    \operatorname{erf}(x)=\frac{2}{\sqrt \pi} \int^x_0e^{-t^2}dt
\end{equation*}
For small $t\ll1$, we can Taylor expand such that 
\begin{equation*}
    e^{-t^2} = 1-t^2+\ldots=\sum^\infty_{n=0} (-1)^n\frac{t^{2n}}{n!}
\end{equation*}
We can integrate this Taylor expansion because integration is safer than differentiation. For example, if we take 
\begin{equation*}
    f(\varepsilon)=\varepsilon\sin \frac{1}{\varepsilon} = \mathcal{O}(\varepsilon)
\end{equation*}
as $\varepsilon\rightarrow 0$ but if we differentiate, we end up getting a $\frac{1}{\varepsilon}$ which blows up. As such, we have that 
\begin{equation*}
    \begin{split}
        \operatorname{erf}(x) &=\frac{2}{\sqrt{\pi}}\sum^\infty_{n=0} \frac{(-1)^n}{n!}\int^x_0 t^{2n}dt \\ &= \frac{2}{\sqrt{\pi}} \sum^\infty_{n=0} \frac{(-1)^n}{n!}\frac{x^{2n+1}}{2n+1} \\
        &= \frac{2}{\sqrt \pi} \left( x-\frac{x^3}{3}+\ldots \right)
    \end{split}
\end{equation*}
We now know the behavior of $x$ close to $0$, but what about as $x\rightarrow \infty$. Let us rewrite the error function in terms of the complementary error function 
\begin{equation*}
    \operatorname{erf}(x)=1-\operatorname{erfc}(x)=1-\frac{2}{\sqrt \pi}\int^\infty_x e^{-t^2}dt
\end{equation*}
and then we integrate by parts to get 
\begin{equation*}
    \operatorname{erf}(x) =1-\frac{2}{\sqrt \pi} \left( -\frac{1}{2t}e^{-t^2} \Bigg|^\infty_x -\frac{1}{2}\int^\infty_x \frac{e^{-t^2}}{t^2} dt\right)
\end{equation*}
which if we integrate by parts multiple times, we get the series 
\begin{equation*}
    \operatorname{erf}(x)=1-\frac{e^{-x^2}}{x\sqrt \pi } \sum^\infty_{n=0}(-1)^n\frac{(2n-1)!!}{(2x^2)^n}
\end{equation*}
Sometimes, the series diverges and therefore adding more terms leads to a diverging from the true value. We can have the inverse of the radius of convergence to be 
\begin{equation*}
    \frac{1}{R}=\lim_{n\rightarrow 0} \frac{a_{n+1}}{a_n} =\lim_{n\rightarrow 0}\frac{(2n+1)!!}{(2n-1)!!} =\lim_{n\rightarrow 0}(2n+1)
\end{equation*}
We now asks what is the optimal $N$ that ensures convergence for the approximation $\sum^N_{n=0}$. This happens when $a_{N+1}\tilde >{} a_N$ and this is when we should stop. For a given $x$, we want to solve 
\begin{equation*}
    (2x^2)^{-(N+1)}a_{N+1} \tilde > (2x^2)^{-N}a_N
\end{equation*}
which implies \begin{equation*}
    \begin{split}
        \frac{a_{N+1}}{a_N}\frac{(2x^2)^N}{(2x^2)^{N+1}} \geq 1 \\
        \frac{2n+1}{2x^2}\geq 1
    \end{split}
\end{equation*}
where $N_{optimal}$ is the solution to the above inequality. We can get that 
\begin{equation*}
    N_{opt}\sim\frac{1}{2}+x^2
\end{equation*}
For the transcendental equation 
\begin{equation*}
    \tan x=x
\end{equation*}
we can see that the line $y=x$ contacts the tangent function right before the tangent blows up. As such, we can guess 
\begin{equation*}
    x=A_n-\delta_n \twen A_n=\frac{\pi}{2}(2n+1)
\end{equation*}
We can plug this into the tangent and express it as 
\begin{equation*}
    \begin{split}
        \tan x &=\frac{\sin(A_n-\delta _n)}{\cos(A_n-\delta _n)}  \\
        &=\frac{\sin A_n\cos \delta_n -\cos A_n \sin \delta_n}{\cos A_n \cos\delta_n +\sin A_n \sin \delta_n} \\
        &= \frac{\cos \delta_n}{\sin \delta_n}
    \end{split}
\end{equation*}
Taking the Taylor series of sines and cosines we have that 
\begin{equation*}
    \tan x =\frac{1-\tfrac{1}{2}\delta^2+\mathcal{O}(\delta^4)}{\delta -\tfrac{1}{6}\delta^3+\mathcal{O}(\delta^5)} = A-\delta
\end{equation*}
which if we pull a $\delta $ out of the denominator and and then cancel it 
\begin{equation*}
    \begin{split}
        1-\frac{1}{3}\delta^2=A\delta-\delta^2 \\
        A\delta =1+\frac{2}{3}\delta^2 \\
        \delta =\frac{1}{A}\left(1+\frac{2}{3}\delta^2+\ldots \right)
    \end{split}
\end{equation*}
and if we use the leading order approximation $\delta \sim \frac{1}{A}$ which we then plug in 
\begin{equation*}
    \delta = \frac{1}{A}\left( 1+\frac{2}{3}\frac{1}{A^2}+\mathcal{O}\left( \frac{1}{A^3}\right) \right)
\end{equation*}
