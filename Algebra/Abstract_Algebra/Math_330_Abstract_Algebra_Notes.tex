\subsection{Modular Arithmetic}
\begin{definition}
    Take $n>0$ and $n\in \Z $. We say that $a,b\in \Z$ are \textit{congruent modulo n} ($a\equiv b \mod{n}$) if $n$ divides $a-b$ ($n|a-b$) or if the remainder of $n/a$ equals the remainder of $n/b$.
\end{definition}
Here are some properties:
\begin{enumerate}
    \item if $a\equiv b \mod n$ and $c\equiv d \mod n$, then $a+c\equiv b+d \mod n$.
    \begin{proof}
        $a\equiv b \mod n$ implies that $n|a-b$ which implies that $\exists q \in \Z$ such that $a-b=nq$. The same can be said for $a\equiv b \mod n$ for some $q' \in \Z$ such that $c-d=nq'$. Adding these equations together we have that $a-b+c-d = (a+c)-(b+d) = n(q+q')$. Since the integers are closed under addition, $q+q'$ is an integer and therefore $n|(a+c)-(b+d)$ and as a result, $a+c\equiv b+d \mod n$.
    \end{proof}
    \item if $a\equiv b \mod n$ and $c\equiv d \mod n$, then $ac\equiv bd \mod n$
    \begin{proof}
        $a\equiv b \mod n$ implies that $n|a-b$ which implies that $\exists q \in \Z$ such that $a-b=nq$. The same can be said for $a\equiv b \mod n$ for some $q' \in \Z$ such that $c-d=nq'$. We can write $ac$ as
        \begin{equation*}
            \begin{split}
                ac &=(b+nq)(d+nq') \\
                &=bd+bnq'+dnq+n^2qq' \\
                \Rightarrow ac-bd&=n(bq'+dq+nqq') 
            \end{split}
        \end{equation*}
        and since everything in the parentheses are integers and the integers are closed under multiplication and addition, their result is an integer and therefore $n|ac-bd$ and $ac\equiv bd \mod n$.
    \end{proof}
    \item Congruence $\!\!\!\!\mod n$ is an equivalence relation
    \begin{proof}
        An equivalence relation is reflexive, symmetric, and transitive. To prove reflexiveness, we show $a\equiv a \mod n \rightarrow n|a-a\rightarrow n|0$ which is always true. To prove symmetry, we have that $a\equiv b \mod n $ implies $(a-b)=nq$ which we can extract a negative sign such that $(b-a)=n(-q)$ and since $-q$ is also an integer, $n|b-a$ and therefore $b\equiv a\mod n$. To prove transitiveness, we say that $a\equiv b \mod n$ implies $a-b=nq$ and $b\equiv c\mod n$ implies $b-c=nr$. We now find that $a-c=b+nq+nr-b =n(q+r)$. Since the integers are closed under addition, $q+r\in \Z$ and therefore $n|a-c$ and $a\equiv c \mod n$.
    \end{proof}
\end{enumerate}
\subsection{Introduction to Groups}
\begin{definition}[Group]
    A group is a set of elements $G$ with a binary operation $*$ that assigns to every pair $(g,h)$ of elements of $G$ another element in $G$ denoted $g*h$. Groups follow the group axioms:
    \begin{enumerate}
        \item Associativity
        \begin{equation*}
            (g_1*g_2)*g_3 = g_1*(g_2*g_3)
        \end{equation*}
        \item There exists an element $e\in G$ that is the identity such that 
        \begin{equation*}
            e*g_1=g_1*e=g_1
        \end{equation*}
        \item Every element has an inverse element denoted $g^{-1}$ such that 
        \begin{equation*}
            g*g^{-1} = g^{-1}*g = e
        \end{equation*}
        \item The set of elements is closed under the group operation (although this is implied in the definition).
    \end{enumerate}
\end{definition}
\begin{example}
    Let us look at some examples
    \begin{enumerate}
        \item The set $(\Z,+)$. Addition is associative, the identity is 0, the inverse of each element $g$ is $-g$. 
        \item The set $(\R_{>0}, \cdot)$ where $\cdot$ denotes regular multiplication. Regular multiplication is associative, the identity is $1$, the inverse element is $\frac{1}{g}$
        \item The set $(\{-2,-1,0,1,2\},+)$. This fails due since it is not closed (take $1+2=3 \notin $ the set
        \item The set $\left(\left\{ \frac{1}{2^n} \right\}, \cdot \right)$. This fails since there is no inverse.
        \item Fix a positive integer $n$. Take the set $\left( \{0,1,2,\ldots,n-1\}, +\mod n\right)$. The identity is 0, addition is associative. The inverse of an element $0\leq a\leq n-1$ is $n-a$ since $(n-a)+a \mod n = n\mod n = 0$. This group is denoted by Fraleigh as $\Z_n$ but more generally denoted as $\Z/n\Z$.
        \item Fix an $n\in \N$. We denote the group GL$_n(\R)$ as the set of invertible $n\times n$ matrices with real entries with the operation of matrix multiplication. Matrix multiplication is associative, the identity is the $n\times n$ identity matrix $I_n$. The inverse of every element $A$ is the inverse matrix of $A$. This group is also known as the \textit{General Linear Group}.
    \end{enumerate}
\end{example}
\subsection{Properties of Groups}
\begin{definition}
    The \emph{order} of a group $G$, denoted $|G|$,is the cardinality of the group/set. If $G$ is finite, then $|G|<\infty$.
\end{definition}
\begin{definition}
    If the group operation $*$ is commutative, then the group is \emph{Abelian}.
\end{definition}
Here are some properties:
\begin{enumerate}
    \item The identity is unique 
    \begin{proof}
        Suppose we have some $f\in G$ such that $f*g=g \,\,\, \forall g\in G$. Then if we compose $f$ with the identity, we should get $f*e =e$. By axiom 2 of the group axioms, we must also have that $f*e=f$ and therefore we have that $f*e=e=f$.
    \end{proof}
    \item Each inverse element is unique.
    \item Cancellation, that is if $a*b=c$ for some $a,b,c\in G$, then $b=a^{-1}*c$. 
    \begin{proof}
        By group axiom 3, there exists an inverse $a^{-1}$. We can then left multiply by $a^{-1}$ such that $a^{-1}*a*b=a^{-1}*c$ and by associativity, we then have $b=a^{-1}*c$.
    \end{proof}
    The consequences of this is that we can make the following observations: $a*b=a*c$ implies that $b=c$ and $b*a=c*a$ implies $b=c$.
\end{enumerate}
For finite groups, we can write a group table where we have the left argument along the rows and the right argument of the operation along the columns. Since Abelian groups are commutative, they have a symmetry across the diagonal. An interesting thing to note with these group tables is that every entry appears only once in each row and column.
\begin{proof}
    If we have a repeated entry in a row, that implies $a*b=a*c$ but by cancellation, we have that $b=c$. For each column, this implies that $b*a=c*a$ which also implies $b=c$.
\end{proof}
\begin{example}

We can immediately fill out the sides adjacent to the header rows by the group axioms (since $e*g=g$) in Table \ref{tab:groupCard2}. Therefore we must have that $a*a=e$ and therefore $a$ is its own inverse. We shall also note if we apply the group operation $n$-times to an element, we can represent it as $a^n=a*a*\ldots*a \,\,\,(n$ times).

\begin{example}
    Let us look at the Quaternion group. The Quaternion group is the set 
\begin{equation*}
    Q_8 = \{ \pm 1, \pm i, \pm j, \pm k\}
\end{equation*}
under standard multiplication. 1 is the identity element and $i^2=j^2=k^2=-1$. Quaternion multiplication is defined as 
\begin{equation*}
    \begin{split}
        ij=k \twen jk =i \twen  ki=j \\
        ji=-k \twen kj=-i \twen ik=-j
    \end{split}
\end{equation*}
This is a group of order 8 and is non-abelian. The inverse of $-1$ is $-1$ and so because of this we can say the inverse $i$ and $-i$ and same for $j$ and $k$. Associativity is also good. This group is the reason why the cross product exists in $\R^3$ and the related Octonion group allows for the existence of the cross product in $\R^7$. 
\end{example}
\begin{example}
    Another important group is the set of complex numbers with norm of 1 under multiplication. In other words, $\{ z\in \C: |z|=1\}$. This is an Abelian group and is of infinite order. This is a group because the norms are all one so multiplication stays within the group ($|z_1||z_2|=|z_1z_2|=1$) and the inverse is also in the group (if $|z_1|=1, \frac{1}{|z_1|} =1$). We can also convert each complex number into its polar form $z=re^{i\theta}\,\,\, r,\theta \in \R$ and since each element has a norm of 1, $r=1$ and we can just take $z_1z_2=e^{i(\theta_1+\theta_2)}$ and since the real numbers are a group under addition, this set of complex numbers also form a group. This group is also used to generate groups which contain the $n^{th}$ primitive roots of unity. To do this, we fix a number $n\in \N$. Then the number 
    \begin{equation*}
        e^{\frac{2k\pi}{n}i} \twen k\in\{1,2,\ldots,n-1\}
    \end{equation*}
    is an $n^{th}$ primitive root of unity. This means that these are roots to the equation $z^n=1$ and the primitive means that $n$ is the smallest power that can satisfy the equation (e.g., no smaller number (let's call $m$) exists such that $z^m=1$). We then say that the set of the $n^{th}$ groups of unity form an Abelian group under multiplication of order $n$. One can see this because multiplication of complex numbers is associative, the identity is 1 ($k=0$ root) 
\end{example}
\begin{definition}
    Suppose $A$ is any set. A permutation is a function $f:A\mapsto A$ that is bijective.
\end{definition}
\begin{proposition}
    The set of all permutations of a set $A$ is a group where the binary operation $*$ is composition and $e$ is the identity permutation.
\end{proposition}
\begin{proof}
    We must first show that the composition of permutations is also a permutation. Let us say that $\sigma,\tau$ are permutations of $A$. We can now prove that $\sigma \tau$ is injective. Suppose
    \begin{equation*}
        (\sigma \tau)(a) = (\sigma\tau )(b) \rightarrow \sigma(\tau(a))=\sigma(\tau(b))
    \end{equation*}
    Since $\sigma$ is a permutation, $\sigma$ is injective and therefore 
    \begin{equation*}
        \tau(a)=\tau(b)
    \end{equation*}
    Using that logic again, $\tau$ is a permutation and therefore injective and 
    \begin{equation*}
        a=b
    \end{equation*}
    To show that this is onto, we have to show that for some $a\in A$, there exists an $x\in A$ such that $a=\sigma\tau (x)$ Since $\sigma$ is onto, there exists a $y\in A$ such that $a=\sigma(y)$. $\tau$ is also surjective and so we can say there exists an $x\in A$ such that $y=\tau(x)$. Putting everything together we have that 
    \begin{equation*}
        a=\sigma(y)=\sigma(\tau(x))=(\sigma\tau)(x)
    \end{equation*}
    As such we have shown that $\sigma \tau$ is a permutation. Now we can check the group axioms. The group operation is associative since function is associative
    \begin{equation*}
        ((\sigma \tau)\rho)(a) =\sigma(\tau(\rho(a)))=\sigma(\tau\rho(a))=(\sigma(\tau \rho))(a) 
    \end{equation*}
    We also denote the identity permutation $\iota $ such that $\iota(a)=a \,\,\, \forall a\in A$. Finally, any permutation is invertible since it surjective and given any $y\in A$, there exists only one $x$ such that $y=\sigma(x)$ since $\sigma$ is bijective. We therefore have that $\sigma^{-1}(y)=x$. We can check that $\sigma^{-1}$ is a permutation by using the fact that $\sigma(\sigma^{-1}(x))=x$. Let us consider $\sigma^{-1}(y)=\sigma^{-1}(x)$ and applying $\sigma$ to both sides we get $x=y$ and hence injectivity. We shall define a $y=\sigma(x)$ and therefore $\sigma^{-1}(y)=\sigma^{-1}(\sigma(x))=x$ for all $y\in A$.
\end{proof}
This group is known as the symmetric group and we denote it $S_A$. The most important symmetric group is when $A=\{1,2,\ldots,n\}$. We denote this group as $S_n$ and it has cardinality $|S_n|=n!$.\\\\ From now on, we will write $a*b$ as $ab$ except when working with groups using $\Z,\R,$ etc. with addition as they will be denoted using the usual addition sign. Instead of denoting the identity as $e$, we shall write $1$ under the same condition as the last where there is no confusion is possible.
\subsection{The Symmetric Group}
Recall that the Symmetric Group $S_n$ is the defined as the set of all permutations of a set $\{1,2,\ldots,n\}$ where the binary operation is composition. The cardinality of $S_n$ is $|S_n|=n!$. Elements of $S_n$ can be written as 
\begin{equation*}
    \begin{pmatrix}
        1&2&3&4&\ldots&n \\k_1&k_2&k_3&k_4&\ldots &k_n
    \end{pmatrix} \text{ where } k_1,\ldots,k_n \in \{1,\ldots, n\}
\end{equation*}
Since we are using composition, we do the permutation $\tau$ before $\sigma$ in the permutation $\sigma \tau$. Let us look at an example to demonstrate 
\begin{example}
    Let us suppose in $S_5$ 
    \begin{equation*}
        \sigma = \begin{pmatrix}
            1&2&3&4&5 \\5&1&2&3&4
        \end{pmatrix} \twen \tau=\begin{pmatrix}
            1&2&3&4&5\\1&3&2&5&4
        \end{pmatrix}
    \end{equation*}
    The permutation $\sigma\tau$ is then 
    \begin{equation*}
        \sigma \tau = \begin{pmatrix}
            1&2&3&4&5\\5&1&2&4&3
        \end{pmatrix}
    \end{equation*}
    We can also find the inverse of a permutation by just going in ``reverse"
    \begin{equation*}
        \sigma^{-1} = \begin{pmatrix}
            1&2&3&4&5 \\3&2&4&5&1
        \end{pmatrix}
    \end{equation*}
\end{example}
\begin{proposition}
    If $n\geq 3$, the group $S_n$ is non-Abelian
\end{proposition}
\begin{proof}
    Let us first just consider the case $n=3$. Consider the following composition of permutations 
    \begin{equation*}
        \begin{pmatrix}
            1&2&3\\2&3&1
        \end{pmatrix}
        \begin{pmatrix}
            1&2&3\\2&1&3
        \end{pmatrix} = \begin{pmatrix}
            1&2&3\\3&2&1
        \end{pmatrix}\\
        \begin{pmatrix}
            1&2&3\\2&1&3
        \end{pmatrix} \begin{pmatrix}
            1&2&3\\2&3&1
        \end{pmatrix}=\begin{pmatrix}
            1&2&3\\1&3&2
        \end{pmatrix}
    \end{equation*}
    We can prove this for higher $n$ by simply sending everything beyond 3 to their number. For example 
    \begin{equation*}
        \begin{pmatrix}
            1&2&3&4&5&\ldots\\2&3&1&4&5&\ldots
        \end{pmatrix}
    \end{equation*}
\end{proof}
\subsubsection{Cycle Notation}
We can express the elements of a group in a more streamlined way.
\begin{equation*}
    (k_1,k_2,\ldots,k_l) \text{ where } k_1,\ldots,k_l \in \{1,2,\ldots,n\} \text{ and are distinct}
\end{equation*}
This notation denotes the following permutation: $k_1\rightarrow k_2\rightarrow\ldots\rightarrow k_{l-1}\rightarrow k_l\rightarrow k_1$. Any numbers not listed in this cycle is assumed to be fixed. In this case we have to specify what symmetric group we are in because the number of fixed entries could be 1 or 2 or 500.
\begin{example}
    In $S_6$, the notation $(3,1,5,4)$ represents the permutation
    \begin{equation*}
        \begin{pmatrix}
            1&2&3&4&5&6\\5&2&1&3&4&6
        \end{pmatrix}
    \end{equation*}
    We can also compose them together as normal 
    \begin{equation*}
        (3,1,5,4)(1,2,6,5,3) =\begin{pmatrix}
            1&2&3&4&5&6\\2&6&5&3&1&4
        \end{pmatrix}
    \end{equation*}
\end{example}
If we want to invert a permutation, we just reverse the order of the terms. For example $\sigma=(k_1,k_2,\ldots,k_l)$ inverts to $\sigma^{-1}=(k_l,k_{l-1},\ldots,k_1)$. Cycles of length 2 are specifically called \emph{transpositions}. We also note that cycles are not unique since we see that the inverse of a cycle $(a,b)$ is $(b,a)$ which is the same as $(a,b)$. There is a fact that if you have 2 cycles are disjoint, that is, they don't have any entries in common, the disjoint cycles commute. Additionally, every permutation can be written as a product of disjoint cycles. 
\begin{equation*}
    \begin{pmatrix}
        1&2&3&4&5&6&7&8\\8&5&3&6&7&4&2&1
    \end{pmatrix} = (1,8)(2,5,7)(3)(4,6)
\end{equation*}
The cycles with just a single element can be excluded.
